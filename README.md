# Монорепозиторий FOSSDEV

Этот репозиторий используется как единое пространство для нескольких учебных FOSSDEV-проектов. Для задания по `Make` в репозиторий добавлен отдельный подпроект в каталоге [`Make`](Make/README.md), оформленный как самостоятельная демонстрация автоматизации окружения, зависимостей и проверок качества кода.

## Где искать решение

Основная точка входа для проверки находится здесь:

- [`Make/README.md`](Make/README.md) — подробная статья о решении, архитектуре `Makefile`, порядке проверки и ожидаемых результатах;
- [`Make/Makefile`](Make/Makefile) — набор автоматизированных таргетов;
- [`Make/src/`](Make/src) — исходный код;
- [`Make/scripts/`](Make/scripts) — служебные скрипты для проверки зависимостей и сборки документационного артефакта;
- [`Make/tests/`](Make/tests) — тесты.

## Что показывает этот проект

Решение построено вокруг идеи, что `Makefile` должен быть не случайным списком команд, а воспроизводимым интерфейсом для команды. Поэтому в подпроекте автоматизированы:

- создание локального виртуального окружения в `.venv/`;
- установка runtime- и dev-зависимостей;
- запуск приложения через интерпретатор проекта;
- проверка импортов относительно `requirements.txt`;
- статическая проверка типов;
- проверка и форматирование стиля;
- тестирование;
- сборка документационного артефакта;
- сборка исполняемого артефакта;
- объединяющий таргет `make check`.

## Логика оценки

Для проверки работы не нужно вручную восстанавливать порядок команд. Достаточно перейти в каталог [`Make`](Make) и использовать описанные в проектной документации таргеты `make`. Такое оформление делает решение прозрачным: из корневого README легко найти нужный подпроект, а из проектного README — понять логику автоматизации и увидеть все ожидаемые результаты.
